# Alumni/Student Voices

The public `khwebpage` homepage reads published rows from
`public.alumni_student_voices`. The Backoffice manages these rows at
`/alumni-student-voices` and stores portrait images in the public Supabase
Storage bucket `alumni-student-voices`. The public Camp Voices section shows
only 3 published people.

## Table and Storage SQL

Run this SQL in the Supabase SQL Editor before using the CMS route.

```sql
create table if not exists public.alumni_student_voices (
  id bigint generated by default as identity primary key,
  name text not null,
  role text not null,
  relation text,
  camp_year text,
  quote text not null,
  image_url text,
  image_alt text,
  display_order integer not null default 0,
  is_published boolean not null default false,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create or replace function public.set_updated_at()
returns trigger
language plpgsql
as $$
begin
  new.updated_at = now();
  return new;
end;
$$;

drop trigger if exists alumni_student_voices_set_updated_at
  on public.alumni_student_voices;

create trigger alumni_student_voices_set_updated_at
before update on public.alumni_student_voices
for each row execute function public.set_updated_at();

alter table public.alumni_student_voices enable row level security;

drop policy if exists "Published alumni/student voices are public"
  on public.alumni_student_voices;
create policy "Published alumni/student voices are public"
on public.alumni_student_voices
for select
to anon, authenticated
using (is_published = true);

drop policy if exists "Editors manage alumni/student voices"
  on public.alumni_student_voices;
create policy "Editors manage alumni/student voices"
on public.alumni_student_voices
for all
to authenticated
using (
  exists (
    select 1
    from public.profiles
    where profiles.id = auth.uid()
      and profiles.role in ('admin', 'editor')
  )
)
with check (
  exists (
    select 1
    from public.profiles
    where profiles.id = auth.uid()
      and profiles.role in ('admin', 'editor')
  )
);

insert into storage.buckets (id, name, public)
values ('alumni-student-voices', 'alumni-student-voices', true)
on conflict (id) do update set public = true;

drop policy if exists "Public reads alumni/student voice images"
  on storage.objects;
create policy "Public reads alumni/student voice images"
on storage.objects
for select
to anon, authenticated
using (bucket_id = 'alumni-student-voices');

drop policy if exists "Editors manage alumni/student voice images"
  on storage.objects;
create policy "Editors manage alumni/student voice images"
on storage.objects
for all
to authenticated
using (
  bucket_id = 'alumni-student-voices'
  and exists (
    select 1
    from public.profiles
    where profiles.id = auth.uid()
      and profiles.role in ('admin', 'editor')
  )
)
with check (
  bucket_id = 'alumni-student-voices'
  and exists (
    select 1
    from public.profiles
    where profiles.id = auth.uid()
      and profiles.role in ('admin', 'editor')
  )
);
```

## Publishing Rules

- Keep `is_published = false` while drafting.
- Set `is_published = true` only when the row is ready for the public site.
- `khwebpage` filters by `is_published = true` and orders by
  `display_order`, then `created_at`, then limits the result to 3 rows.
- The Backoffice form blocks publishing a fourth visible voice; keep extra
  records as drafts until one of the 3 visible rows is unpublished.
- Do not use service-role keys in either frontend. Backoffice writes through
  the logged-in Supabase session and RLS policies.
